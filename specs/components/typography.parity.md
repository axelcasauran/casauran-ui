## Provenance and clean-room review

The mandatory local-only preflight passed against snapshot
`2b68481b897ab216625fd264a10fb323fc0071c2a589f893c488d13e91ff4862`. Every examined path — two
component pages, four API pages, seven package and styling pages, and four positioning and
packaging pages — is recorded in `typography.reference-analysis.md`, together with the five
cross-cutting families searched and found to carry no requirement and the example directories
deliberately not used as implementation input. The implementation was produced from
`typography.spec.md`; no source, CSS, theme value, class name, asset, bundle, private
architecture, undocumented DOM, online fallback, or runnable example file was used as
implementation input.

## Disposition vocabulary

Every materially relevant capability carries exactly one disposition: `IMPLEMENTED`,
`IMPLEMENTED_DIFFERENTLY`, `NOT_APPLICABLE`, `INTENTIONALLY_DIVERGED`,
`DEFERRED_TO_DECLARED_DEPENDENCY`, or `BLOCKED`. A silent omission and an unowned deferral are not
acceptable final states. Deferral names the owning stage.

## Manual accessibility and visual review

The rendered semantics and the Chromium visual baseline were inspected by hand. The review
confirmed that a heading element carrying display type is announced as exactly one heading at its
own level and nothing else; that a paragraph carrying title type produces no heading, no `role` and
no `aria-level`; that a level-three heading set at caption size keeps its level; that the accessible
name of an uppercased element is its unchanged text rather than its rendered casing; that a
multi-line code block reads as preformatted text with its newlines intact and an injected script tag
visible as characters; that the quotation rule moves to the right edge in the right-to-left panel
and the inline-start spacing indents from the reading edge; that at 320 CSS pixels and at a doubled
root font size nothing is clipped and the long code line scrolls inside its own block; and that
under forced colours every tone collapses to the system foreground while the quotation rule stays
visible. The review makes no claim of an external screen-reader certification matrix that was not
executed.

## Deliberate independent improvements

- The document outline and the type scale are separate decisions, so no author has to corrupt one
  to obtain the other. This is the capability the analysed model most lacked.
- Content is children, so there is no injection sink to review, no sanitizer to keep correct, and no
  content-security-policy relaxation to request — including for the multi-line code block that is
  the case a raw-markup path exists to serve.
- Alignment and every spacing side are logical, so one declaration is correct in both directions and
  a right-to-left layout needs no second stylesheet.
- Every named step resolves to exactly one governed token in every theme, so `bold`, `md` and `lg`
  mean the same thing wherever they are read.
- The component resets the browser's own element margins, so vertical rhythm is declared rather than
  inherited and then fought with per-application CSS.
- The tone vocabulary carries no two public names for one colour, so the defect Icon's revalidation
  removed cannot reappear here.
- The element vocabulary excludes every interactive element, so a text primitive can never become a
  second, unowned action surface.

## Gaps, debt, and boundary

No in-scope parity gap, architecture debt, dependency debt, security exception, or unexplained
capability remains: every row above carries a disposition, no row defers, and every
`NOT_APPLICABLE` row names the owning subsystem and why Typography is not that owner. A bound
element namespace, a light weight step, physical alignment and physical margin sides, an unbounded
numeric spacing multiplier, a raw-markup content path, interactive elements, truncation, layout of
multiple blocks, a utility-class vocabulary, licensing tiers and design-tooling artefacts all remain
outside this component.
