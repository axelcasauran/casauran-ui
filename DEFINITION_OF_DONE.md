# Component Definition of Done

Applicable gates: specification, independent API, implementation, unit tests, browser interaction, keyboard, accessibility, themes/dark/density, RTL, responsive/adaptive, Next.js, SSR, hydration, i18n/IME, performance, security, docs/examples, visual regression, public exports, dependency policy and parity audit.

Documentation is done when every declared feature is demonstrated on the component's route under
`DOCUMENTATION_POLICY.md`: a preview per enumerated value, a section for behaviour with nothing to
render, or a named browser/visual case for environment-conditional behaviour. One representative
value does not document a scale.

`not-applicable` requires an explicit reason in stage evidence; it is never a silent skip.
