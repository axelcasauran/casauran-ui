## Delivered scope

Exactly one public component, `SVGIcon`: the direct-definition icon surface, where the caller owns
the drawing. It supports caller-owned definitions, three governed drawing variants with an
observable fallback, per-layer paint, stroke weight, fill rule and opacity, a definition-owned view
box with a platform default, runtime definition narrowing, fail-closed rendering for an unusable
definition, catalog interoperability, the shared seven-step size scale, the shared seven-value
semantic tone scale, four mirroring values, decorative-by-default semantics with a single labelling
escape, a two-token theming seam, RTL, forced colours, SSR/RSC, and native attribute passthrough.

`@casauran/icons` was extended at its owner layer with the `SVGIconDefinition`, `IconPath` and
`SVGIconVariant` types, the `isSVGIconDefinition` guard, the `resolveSVGIcon` resolver,
`svgIconVariants`, and the `SVG_ICON_DEFAULT_VIEW_BOX` and `SVG_ICON_DEFAULT_STROKE_WIDTH`
constants. `Icon` and `Button` are unchanged.

## Decisions, debt, and blockers

- The drawing is structured data rather than a markup string. This is the stage's defining
  divergence and the reason it has no injection sink; it is recorded in advance in the reference
  analysis and as capability 2 of the parity audit.
- Variants are a closed union rather than an open keyspace, consistent with `IconName`, `tone` and
  `size`.
- Stroke weight is a per-layer definition property, not a CSS token, because it belongs to the
  caller's drawing and one drawing may mix weights.
- SVGIcon reuses Icon's size, tone and flip vocabularies rather than declaring parallel ones. Its
  stylesheet repeats those rules against its own class and its own two component tokens; that is
  per-component styling, not a duplicated engine, and giving it Icon's tokens would have made one
  consumer override silently affect both components.
- No new debt is created and no capability is deferred. The parity audit records 0
  `DEFERRED_TO_DECLARED_DEPENDENCY` rows.
- Open, not owned by this stage: the Phase 0 re-certification recorded in `.agent/status.md`,
  including the Firefox and WebKit baseline set and the `theme-runtime` Chromium baseline.

## Boundary audit

Exactly one public React component, `SVGIcon`, shipped. The `@casauran/icons` extension is data and
validation at the declared owner of vector definitions, not a second React component.

Deliberately not built: raw SVG or HTML acceptance in any form; arbitrary children; a component-level
view-box override; an open variant keyspace; a styling target for the nested `<svg>`; icon fonts, a
glyph class vocabulary, or a Unicode escape; an ambient icon provider or icon-type switch; a runtime
class-replacement provider; a bundled catalog of hundreds of glyphs; migration codemods; a custom ref
handle; loading orchestration; and any agent command surface. No catalog variants were added to
`@casauran/icons`, because a catalog glyph ships one drawing. `Icon`, `Button` and stage `1.04`
were not touched.
