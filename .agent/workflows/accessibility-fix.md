# Workflow: accessibility-fix

## Purpose
Repair semantic/interaction accessibility.

## Entry conditions
- Active stage/phase known.
- Governing policies and relevant skills loaded.
- Acceptance criteria established.

## Procedure
1. identify pattern issue.
2. reproduce keyboard/screen-reader path.
3. fix owner.
4. automate meaningful checks.
5. record manual evidence.

## Records
- affected stage/phase
- decisions/evidence
- tests/validators
- debt/follow-up

## Hard gates
- semantic HTML first.

## Exit
Update authoritative registry/stage/status and stop at workflow boundary.
