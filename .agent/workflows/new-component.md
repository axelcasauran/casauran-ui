# Workflow: new-component

## Purpose

Execute standard one-component stage.

## Entry conditions

- Active stage/phase known.
- Governing policies and relevant skills loaded.
- Acceptance criteria established.

## Procedure

1. reference-to-spec.
2. registry.
3. API.
4. composition review.
5. implementation.
6. tests.
7. docs.
8. parity audit.
9. close.

## Records

- affected stage/phase
- decisions/evidence
- tests/validators
- debt/follow-up

## Hard gates

- exactly one public component.

## Exit

Update authoritative registry/stage/status and stop at workflow boundary.
