# Workflow: architecture-change

## Purpose
Change frozen architecture deliberately.

## Entry conditions
- Active stage/phase known.
- Governing policies and relevant skills loaded.
- Acceptance criteria established.

## Procedure
1. state evidence.
2. list options.
3. compatibility/migration analysis.
4. ADR.
5. approval.
6. migration implementation.
7. validators/docs update.

## Records
- affected stage/phase
- decisions/evidence
- tests/validators
- debt/follow-up

## Hard gates
- no drift in ordinary PR.

## Exit
Update authoritative registry/stage/status and stop at workflow boundary.
