# Workflow: performance-regression

## Purpose
Investigate measured regression.

## Entry conditions
- Active stage/phase known.
- Governing policies and relevant skills loaded.
- Acceptance criteria established.

## Procedure
1. reproduce benchmark.
2. control variance.
3. profile.
4. locate owner.
5. fix.
6. compare before/after.
7. verify correctness.

## Records
- affected stage/phase
- decisions/evidence
- tests/validators
- debt/follow-up

## Hard gates
- no accessibility/correctness sacrifice.

## Exit
Update authoritative registry/stage/status and stop at workflow boundary.
