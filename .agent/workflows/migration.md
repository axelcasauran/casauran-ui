# Workflow: migration

## Purpose
Manage deprecated/breaking behavior.

## Entry conditions
- Active stage/phase known.
- Governing policies and relevant skills loaded.
- Acceptance criteria established.

## Procedure
1. identify API.
2. old/new examples.
3. codemod/manual steps.
4. version/deprecation schedule.
5. test migration.

## Records
- affected stage/phase
- decisions/evidence
- tests/validators
- debt/follow-up

## Hard gates
- no silent stable break.

## Exit
Update authoritative registry/stage/status and stop at workflow boundary.
