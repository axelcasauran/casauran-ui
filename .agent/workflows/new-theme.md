# Workflow: new-theme

## Purpose
Add/evolve independent theme.

## Entry conditions
- Active stage/phase known.
- Governing policies and relevant skills loaded.
- Acceptance criteria established.

## Procedure
1. define token mapping.
2. verify component token coverage.
3. test light/dark/density/RTL.
4. visual matrix.
5. document deviations.

## Records
- affected stage/phase
- decisions/evidence
- tests/validators
- debt/follow-up

## Hard gates
- no proprietary copy.

## Exit
Update authoritative registry/stage/status and stop at workflow boundary.
