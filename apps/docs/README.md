# Casauran UI documentation

Next.js App Router host on port 3100. This is the canonical customer documentation experience;
`apps/playground` remains the engineering sandbox.

Routes are Server Components by default; client components are introduced only where interaction requires them.

F0.18 provides the shared shell, stable component routes and section anchors, registry-derived
navigation/search metadata, example/source panels, API tables, accessibility/keyboard structures,
callouts, presentation controls, responsive behavior, and deterministic production visual tests.
Future component stages compose these private structures and import only supported public APIs.
