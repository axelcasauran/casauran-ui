# Theme Policy
Required: default light/dark, density, RTL via logical CSS, forced-colors, reduced-motion and consumer overrides.

Planned independent visual families: Material-inspired, Bootstrap-inspired, Fluent-inspired. They are independent interpretations, not copies of proprietary Kendo theme source/values/selectors/assets.

Theme switching should avoid hydration mismatch, using server-compatible attributes and CSS variables when practical.
